Get started

Install takes about a minute. The same zip works on both systems.

Windows

YOUR SYSTEM

Run the installer, restart After Effects, and open the panel.

  1. Close After Effects.
  2. Unzip RuMotion-CEP.zip.
  3. Double-click install.bat.
  4. Start After Effects and open Window → Extensions → Ru Motion.
Windows install help

Mac

YOUR SYSTEM

Same steps with the Mac installer. macOS may ask you to confirm it once.

  1. Close After Effects and unzip the file.
  2. Double-click install.command. If macOS blocks it, right-click, choose Open, then confirm.
  3. Start After Effects and open Window → Extensions → Ru Motion.

GOOD TO KNOW

Why the installer sets debug mode

The panel is not signed by Adobe, so After Effects needs one setting to load it. The installer sets it for you.
