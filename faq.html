01How do I install it on Windows?

WindowsIt takes about a minute:

  1. Close After Effects.
  2. Unzip RuMotion-CEP.zip.
  3. Double-click RuMotion-Setup. A window opens, copies the panel and sets the permissions, then tells you it is done.
  4. Start After Effects and open Window → Extensions → Ru Motion. Dock it wherever you like.
02How do I install it on Mac?

MacSame idea, with the Mac installer:

  1. Close After Effects and unzip RuMotion-CEP.zip.
  2. Double-click RuMotion-Setup. If macOS blocks it, right-click the file, choose Open, then confirm.
  3. Start After Effects and open Window → Extensions → Ru Motion.

If it still will not run, open Terminal, type chmod +x , drag RuMotion-Setup into the window and press Enter. Then double-click it again.

03Ru Motion is not in the Window → Extensions menu. What now?

Check these in order:

  1. Restart After Effects. It only loads panels at startup.
  2. Run the installer again with After Effects closed.
  3. Check the folder. It should be here, with index.html, CSXS and jsx directly inside RuMotion, not inside another folder:
    • Windows%APPDATA%\Adobe\CEP\extensions\RuMotion
    • Mac~/Library/Application Support/Adobe/CEP/extensions/RuMotion
  4. Check your version. You need After Effects 2019 or newer.
04What does “PlayerDebugMode” do, and is it safe?

After Effects only loads panels that Adobe has signed. The installer sets one setting that lets it load unsigned panels such as this one. It affects only your own user account, and only panels you have installed yourself.

To turn it off again (Ru Motion and any other unsigned panel will then stop loading):

WindowsIn Registry Editor, delete the PlayerDebugMode value under HKEY_CURRENT_USER\Software\Adobe\CSXS.12 (and the other CSXS keys).

MacIn Terminal:

defaults delete com.adobe.CSXS.12 PlayerDebugMode
05The panel opens but says “Starting Ru Motion…” or shows an error.

Close and reopen the panel first, then restart After Effects. The first start of a session takes a few seconds because the effects load once.

WindowsA downloaded zip can be marked as blocked. Right-click the zip, open Properties, tick Unblock, then unzip and run the installer again.

If the message stays, email a screenshot of it and your After Effects version to tlakshan10106@gmail.com.

06Do I need to delete the old version before updating?

No. Close After Effects and run the new installer. It removes the old folder first and then copies the new one, so nothing is left over to clash.

Your saved settings (colors, fonts, presets) live in After Effects’ own preferences, so an update does not reset them. If the installer shows an error, close After Effects and run it again.

07Do I need to keep the downloaded folder?

No. The panel runs from the copy the installer made in the extensions folder. After installing you can delete the zip and the unzipped folder.

08Which After Effects versions work?

After Effects 2019 (version 16) and later, on both Windows and Mac. The same panel folder is used on both systems; only the installer differs.

Older versions cannot load it. Use the single RuMotion.jsx instead (see question 10).

09Some buttons do nothing, or presets are not applied.

Some buttons, such as the text presets, write a small temporary file. In After Effects, open Preferences → Scripting & Expressions and turn on Allow Scripts to Write Files and Access Network. Restart After Effects afterwards.

Also check that a layer is selected and the playhead is where the effect should start. Each button’s tooltip says what it needs.

10Can I use the single RuMotion.jsx instead?

Yes. Copy RuMotion.jsx into After Effects’ Scripts/ScriptUI Panels folder, restart, and open it from the Window menu. It is an older style of panel: no mouse-wheel scrolling, and a little slower.

You can also run it once without installing: File → Script → Run Script File. It opens as a floating window.
